## 🎯 为什么做这套系统

贷款中介公司的日常，往往被这些问题拖垮：

| 痛点 | 助贷 CRM 的解法 |
| :--- | :--- |
| 📋 客户资料躺在 Excel 和微信里，业务员撞单、离职带走客户 | **线索池 → 客户公海 → 跟进留痕**，全程系统化沉淀，谁跟进、跟进到哪一步一目了然 |
| 🧮 佣金靠嘴算、月底对不上账，团队为分钱扯皮 | **先定佣金池、再按贡献比例分配**，池子与比例全程快照留痕，规则透明 |
| 📉 放款了多少、实收了多少、净赚了多少，一笔糊涂账 | **实收 / 成本 / 净业绩 / 佣金四账分立**，与贷款本金完全解耦，财务口径清晰 |
| ✏️ 历史业绩改了就查不到，出了纠纷说不清 | **业绩版本链**：确认后纠错不覆盖历史，每一版谁改的、为什么改，全部留痕 |
| 📞 业务员打没打电话全靠嘴说，跟进质量没法管 | **安卓协同拨号 + 独立通话记录**：系统内一键拨号，通话状态、录音留痕可查 |
| 💸 买线索花的钱和赚回来的业绩对不上账 | **数据成本核算**：按首次分配归属摊到人与渠道，获客投入与业绩产出同表对账 |
| 🏢 多门店 / 多团队各管一摊，老板看不到全局 | **多租户 + 部门数据权限**，一套系统管全部团队，数据按角色隔离 |

> 系统内置的进件模型专为助贷场景设计：业务员在线下帮客户完成放款后，**一键上报业绩**，渠道部门核实放款真实性——不是银行贷前审批流程的生搬硬套。

### ④ 通话记录 —— 安卓协同拨号，打电话也留痕

### ⑥ 放款上报（进件）—— 一次放款、一笔成交，杜绝重复申报

业务员上报线下放款业绩，渠道部门核实真伪；**幂等校验 + 乐观锁 + 唯一约束三层防重**，同一笔放款绝不可能申报两次；核实不通过可**退回补正**（业务员补齐放款事实后重新提交），每一步状态流转自动留痕。

![放款上报列表](screenshots/19-放款上报.png)

上报工作区：选客户 → 匹配产品（自动推荐可做方案）→ 填报放款事实，一屏完成。

![上报放款](screenshots/20-上报放款.png)

进件详情：客户资质、产品方案、放款信息、状态时间线（谁操作、何时操作全留痕）、业绩信息一屏聚合。

### ⑦ 业绩核算 —— 财务口径的净业绩，不是流水账

实收服务费、渠道返佣、逐笔直接成本分账登记，自动得出**净业绩**；房租底薪等期间费用不摊入单笔业务，口径干净。每笔已核实进件对应一张业绩单，版本与状态一目了然。

![业绩核算](screenshots/23-业绩核算.png)

佣金池工作台（已确认）：**第一步定实收 → 第二步定佣金池 → 第三步按贡献比例分配**。参与人、比例、金额全部快照留痕；历史确认后需要纠错？生成新版本，老版本永久可查——**不以当前人员关系覆盖历史**。

![业绩详情-佣金池分配-已确认](screenshots/24-业绩详情-佣金池分配-已确认.png)

新核实的进件进入「待确认」向导：财务逐笔录入实收流水与凭据号，提交确认后才生成佣金——**业绩必须财务亲手确认，业务员说了不算**。

![业绩详情-待确认向导](screenshots/25-业绩详情-待确认向导.png)

按人汇总佣金明细，关联业绩单与进件单据，误核实可整批撤销重算。

![佣金管理](screenshots/26-佣金管理.png)

## 🧱 技术架构（懂行的看这里）

| 层 | 选型与工程实践 |
| :--- | :--- |
| 后端 | Java 17 · Spring Boot 3.4 · 模块化单体（15 个业务模块，controller → service → repository 分层） |
| 前端 | Vue 3 · TypeScript(strict) · Element Plus · Pinia · Vite |
| 数据 | MySQL 8 · Flyway 版本化迁移 · MyBatis-Plus（全 SQL 显式租户条件） |
| 安全 | JWT 多端会话 · Redis 会话与权限缓存 · 手机号默认脱敏 + 独立查看审计 · 全链路操作日志 |
| 可靠性 | 状态机驱动（具名命令流转，拒绝裸 updateStatus）· 幂等键 + 乐观锁 + 唯一约束三层防重 · 业绩版本链纠错留痕 · 异步导出任务（持久化恢复 + 下载权限校验） |
| 协同 | 安卓端协同拨号（通话任务 + 不可变事件流 + 录音库，团队录音权限共享）· 实时推送 |
| 扩展 | 渠道开放接口（`/api/open/v1`，密钥签名 + 报文加密，广告渠道线索自动入库分配）· 事实表只读报表 |
| 部署 | 已验证公网原生部署（Nginx 反代 + HTTPS IP 证书自动续期）· Docker Compose 一键起 |

## 💼 适用场景与合作方式

- **贷款中介 / 助贷公司**：单团队或总部 + 多门店，开箱即用
- **渠道联盟 / 居间团队**：多租户模式统一供货，各团队数据独立
- **定制交付**：业务口径、佣金规则、报表口径可按需定制

支持**源码买断 / 私有化部署 / 定制开发**多种合作方式，可提供完整在线演示环境。
